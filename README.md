# SaySushi

Сайт-вітрина SaySushi (Say Food House, Зазим'є): меню з фото, кошик з розрахунком доставки по зонах, контакти.
Оформлення: кошик збирається в готовий текст замовлення, який гість надсилає SMS або диктує телефоном. Онлайн-меню закладу: https://saysushi.choiceqr.com.

- `index.html`: сторінка, стилі й логіка
- `data/menu.js`: меню, ціни й зони доставки, скопійовані з ChoiceQR
- `img/`: фото страв, великі фото для hero й банерів, логотип
- `fonts/`: шрифти Onest і Unbounded (OFL), щоб не залежати від Google Fonts

Хоститься на GitHub Pages: https://d1ms0n.github.io/saysushi/
